# Lesson 04 – Destructuring

## Overview

This lesson introduces **Destructuring**, an ES6 feature that allows values to be extracted from objects and arrays using concise syntax. Destructuring improves code readability and reduces repetitive property and index access.

---

## Concepts Covered

* Object Destructuring
* Array Destructuring
* Property Renaming
* Default Values
* Skipping Array Elements
* Dynamic HTML Generation
* DOM Manipulation
* Template Literals

## Exercises

### Exercise 1

* Create a student object.
* Extract its properties using object destructuring.

### Exercise 2

* Create a laptop object.
* Rename a property while destructuring.

### Exercise 3

* Use a default value during object destructuring.

### Exercise 4

* Extract the first and third elements from an array.

### Exercise 5

* Skip the second element while destructuring an array.

---

## Mini Project

Create an **Employee Information Card** that:

* Creates an employee object.
* Extracts values using object destructuring.
* Uses a default value for the country.
* Displays employee information inside an HTML card.
* Formats the salary using the ₹ symbol.
