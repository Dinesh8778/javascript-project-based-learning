# Lesson 02 – Arrow Functions

## Overview

This lesson introduces **Arrow Functions**, a modern JavaScript feature introduced in ES6. Arrow functions provide a shorter and cleaner syntax for writing functions and are widely used in modern JavaScript, React, and Node.js applications.

---

## Concepts Covered

* Arrow Functions
* Function Syntax
* Parameters
* Implicit Return
* Explicit Return
* Callback Functions
* Event Listeners
* DOM Manipulation
* Template Literals

## Exercises

### Exercise 1

* Convert a traditional function into an arrow function.

### Exercise 2

* Create an arrow function to calculate the square of a number.

### Exercise 3

* Create an arrow function to check whether a number is even.

### Exercise 4

* Create an arrow function to return the larger of two numbers.

### Exercise 5

* Create an arrow function to return the length of a string.

## Mini Project

Create a **Simple Calculator** that:

* Accepts two numbers as input.
* Performs Addition.
* Performs Subtraction.
* Performs Multiplication.
* Performs Division.
* Displays the result on the webpage.
* Handles division by zero.
