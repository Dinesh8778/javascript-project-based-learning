\# Lesson 01 – Let \& Const



\## Overview



This lesson introduces the modern JavaScript variable declarations `let` and `const`. It explains when to use each keyword, how block scope works, and why they are preferred over `var` in modern JavaScript.



\---



\## Concepts Covered



\* `let`

\* `const`

\* Block Scope

\* Variable Reassignment

\* Variable Redeclaration

\* Immutable References

\* DOM Selection (`getElementById`)

\* Event Listeners

\* Functions

\* Conditional Statements

\* Template Literals

\## Exercises



\### Exercise 1



\* Declare variables using `let` and `const`

\* Print their values



\### Exercise 2



\* Store a score

\* Update the score

\* Print the updated value



\### Exercise 3



\* Declare a constant

\* Attempt to reassign it

\* Observe the error



\### Exercise 4



\* Practice block scope using `let`



\### Exercise 5



\* Modify an object's property declared with `const`

\* Understand the difference between modifying an object and reassigning it

\## Mini Project



Create a \*\*Student Attendance Counter\*\* that:



\* Stores the school name using `const`

\* Stores attendance using `let`

\* Increases attendance using an \*\*Add\*\* button

\* Decreases attendance using a \*\*Remove\*\* button

\* Prevents attendance from going below `0`

\* Limits attendance to a maximum of `60`

\* Displays attendance status:



&#x20; \* Class Empty

&#x20; \* Low Attendance

&#x20; \* Normal Attendance

&#x20; \* High Attendance

&#x20; \* Class Full
