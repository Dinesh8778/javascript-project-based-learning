# Lesson 03 – Template Literals

## Overview

This lesson introduces **Template Literals**, a modern JavaScript feature introduced in ES6. Template literals make string creation cleaner and more readable by allowing string interpolation, multi-line strings, and expression evaluation using backticks.

---

## Concepts Covered

* Template Literals
* Backticks (`` ` ``)
* String Interpolation (`${}`)
* Multi-line Strings
* Expression Evaluation
* Ternary Operator inside Template Literals
* DOM Manipulation
* `innerHTML`
* Dynamic HTML Generation

## Mini Project

Create a **Student Report Card** that:

* Accepts student details:

  * Name
  * Department
  * College
  * Three Subject Marks
* Calculates:

  * Total Marks
  * Average
  * Pass / Fail Result
* Displays a formatted report card using **one template literal**.
* Highlights failed marks using different text colors.
