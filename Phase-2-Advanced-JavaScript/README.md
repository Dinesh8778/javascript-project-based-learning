\# JavaScript Phase 2 – Modern JavaScript (ES6+)



\## Overview



This phase focuses on modern JavaScript (ES6+) features used in real-world web development. The lessons in this phase build on JavaScript fundamentals and introduce cleaner syntax, better coding practices, asynchronous programming, and browser APIs.



Each lesson includes theory, hands-on exercises, a mini project, and a README documenting the concepts learned.



\---



\## Topics Covered



\* Let \& Const

\* Arrow Functions

\* Template Literals

\* Destructuring

\* Spread Operator

\* Rest Parameters

\* Default Parameters

\* ES Modules

\* Promises

\* Async / Await

\* Fetch API

\* Local Storage



\---



\## Mini Projects



Each lesson contains a mini project designed to reinforce the concepts learned in that lesson.



Projects will gradually increase in difficulty and use only the concepts covered up to that point.

\## Learning Goals



By completing this phase, I aim to:



\* Write clean and modern JavaScript code

\* Understand ES6+ syntax and features

\* Improve code readability and maintainability

\* Work with objects and arrays efficiently

\* Understand asynchronous programming

\* Consume REST APIs using Fetch API

\* Store data in the browser using Local Storage

\* Build interactive web applications using modern JavaScript



\---



\## Learning Outcome



After completing Phase 2, I will have a solid understanding of modern JavaScript features and be able to build responsive, interactive, and data-driven web applications using industry-standard JavaScript practices.
