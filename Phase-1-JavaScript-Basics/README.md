# 🚀 Phase 1 – JavaScript Fundamentals

## 📖 Overview

Welcome to **Phase 1** of my **JavaScript Project-Based Learning Journey**.

This phase focuses on building a strong foundation in JavaScript by learning the core concepts step by step through hands-on coding exercises and mini projects.

Instead of only learning theory, every lesson was followed by practical exercises and a real-world mini project, helping me understand how JavaScript works in practice.

By the end of this phase, I gained confidence in writing JavaScript programs, solving logical problems, manipulating web pages, and creating interactive user experiences.

---

# 🎯 Objectives

* Learn JavaScript fundamentals from scratch.
* Understand programming logic and problem-solving.
* Practice writing clean and readable code.
* Build mini projects using only learned concepts.
* Learn Git and GitHub by pushing every lesson and project.
* Prepare for modern JavaScript (ES6+), React, and Node.js.
